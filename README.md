# Parth Solanki - Personal Cybersecurity Portfolio

A high-performance, dark cyberpunk-themed portfolio website tailored for an Offensive Security Specialist, Bug Bounty Hunter, and Red Teamer.

## Features
- **Cyber Aesthetic**: Dark slate background with neon cyan, green, and purple accents.
- **Interactive Cyber Terminal**: Simulated Bash environment with command execution (`whoami`, `skills`, `cve`, `hof`, `contact`, `clear`).
- **Showcases**:
  - Web & API Security capabilities (BOLA/IDOR, SSRF, Concurrency/Race Conditions, OAuth).
  - Hall of Fame recognitions and responsible disclosures.
  - Anonymized research breakdowns and case study modals.
- **Responsive**: Fully optimized for mobile, tablet, and widescreen displays.
- **Zero Dependencies**: Pure HTML5, CSS3, and JavaScript — ready for instant deployment on **GitHub Pages**.

## Local Development
To preview the website locally:
```bash
./run_preview.sh 8080
```
Then visit `http://localhost:8080`.

## Deployment (GitHub Pages)
This repository is pre-configured for GitHub Pages.
1. Push to your GitHub repository (e.g. `username.github.io` or `portfolio`).
2. In your GitHub repository: go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/`!
